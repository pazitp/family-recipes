# המתכונים שלנו 🍲

אפליקציית המתכונים המשפחתית — GitHub Pages + Firebase (פרויקט `family-recipes-e9d80`, משותף עם my-tasks).

- **כתובת:** https://pazitp.github.io/family-recipes/

## הוספת מתכון דרך issue

אפשר להוסיף מתכון על ידי פתיחת issue במאגר (כך קלוד מוסיף מתכונים מהצ'אט).
זה עובד רק ל-issues שנפתחו מהחשבון `pazitp` ושכותרתם מתחילה ב-`מתכון:`.
מה שאחרי הקידומת הופך לשם המתכון. אפשר גם ידנית: Actions ‣ add-recipe ‣ Run workflow.

גוף ה-issue:

```
מקור: רינה, ווצאפ
תגיות: סלטים, חגים
מנות: 10
הכנה: 20
בישול: 0
הערת זמן: טקסט חופשי

מצרכים:
2 | יחידה | סלק גדול
1/2 כוס שמן זית
2 כפיות חרדל
4 שיני שום
מלח

שלבים:
1. לקלף ולגרד.
2. לערבב רוטב.
```

- שורות המטא (מקור, תגיות, מנות, הכנה, בישול, הערת זמן) כולן רשות; מנות ברירת מחדל 4.
- מצרך: או `כמות | יחידה | שם` או טקסט חופשי (`2 כוסות קמח`, `4 שיני שום`, `מלח`).
  יחידות מוכרות: גרם, ק"ג, מ"ל, ליטר, כוס, כף, כפית, יחידה, חבילה, קורט, לפי הטעם
  (וגם ריבוי כמו כוסות/כפות/כפיות). מילה לא מוכרת אחרי מספר הופכת לחלק מהשם עם יחידה "יחידה".
- שלבים: שורה לכל שלב, מספור בתחילת השורה מוסר.
- מתכון בשם קיים לא יתווסף פעמיים.

בהצלחה תתווסף ל-issue תגובה "✔ נוסף לאפליקציה" והוא ייסגר; בכישלון תתווסף תגובה עם קישור ללוג.

## התקנה חד-פעמית

במאגר הזה צריך את הסוד `FIREBASE_SERVICE_ACCOUNT` (Settings ‣ Secrets and variables ‣ Actions ‣ New repository secret):
אותו JSON של ה-service account שכבר שמור ב-my-tasks. אם קובץ ה-JSON לא נשמר, מייצרים מפתח חדש
במסוף Firebase ‣ Project settings ‣ Service accounts ‣ Generate new private key.
